# Petunjuk File Musik

Letakkan file lagu audio di folder ini dengan nama:
`hannah-montana.mp3`

Lokasi berkas:
`public/music/hannah-montana.mp3`

Lagu yang disarankan:
**"Hannah Montana" – Rex Orange County**

Format yang didukung: `.mp3`, `.m4a`, `.ogg`.
Jika file `hannah-montana.mp3` belum dimasukkan, website akan secara otomatis menggunakan melodi piano romantis lembut bawaan (*Web Audio API*) agar tombol play tetap berfungsi dan tidak terjadi error.
